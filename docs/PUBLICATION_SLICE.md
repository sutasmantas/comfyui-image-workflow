## Acceptance contract

This slice replaces the weak geometric SVG with a generated campaign fixture,
keeps the no-key path free to run, and makes the implemented orchestration
contract legible to a client. It passes only when the repository shows the
parameterized seven-node ComfyUI API-format graph, serialized queue, progress,
provider failure, linked retry, artifact SHA, and explicit adapter boundary.

It must not claim that Printline executed a live ComfyUI model, used a hosted
GPU, benchmarked image quality, or produced the fixture itself. A paid model is
not required for this bounded publication outcome.
